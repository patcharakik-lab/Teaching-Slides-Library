## 1. จุดเด่นและระบบการทำงานของสื่อการสอน (Key Features)

1. **Responsive 16:9 Canvas (1600 × 900 px):**
   - ออกแบบด้วยสัดส่วน 16:9 มาตรฐาน และใช้ระบบ Uniform Scaling คำนวณขยาย/ย่อตามขนาดหน้าจอจริง (1920×1080, 1600×900, 1366×768, 1280×720)
   - แถบเครื่องมือด้านบนและล่างแยกอิสระจากพื้นที่สไลด์ ป้องกันการบดบังเนื้อหา

2. **Smart Adaptive Typography (ป้องกันข้อความล้น):**
   - ควบคุมขนาดตัวอักษรและ Line Height ตามข้อกำหนด V10
   - ตรวจสอบ `scrollHeight` และ `clientHeight` อัตโนมัติหลัง `document.fonts.ready`
   - ปรับลด Font Size, Padding, Gap และขนาดภาพอย่างชาญฉลาดโดยไม่ตัดทอนข้อความ

3. **Interactive Learning Systems (ระบบโต้ตอบที่ใช้งานได้จริง):**
   - **Before / After Comparison Slider (สไลด์ 5):** เลื่อนเปรียบเทียบผลลัพธ์ระหว่าง "ถ่ายทำทันทีโดยไม่วางแผน" กับ "วางแผนก่อนถ่ายทำ" รองรับทั้งเมาส์ลาก, สัมผัสบนจอ Touch, Range Input และปุ่มลูกศรคีย์บอร์ด
   - **Interactive Storyboard Explorer (สไลด์ 23):** คลิกดูรายละเอียดฉากที่ 1 ถึง 6 (30 วินาที) แสดงขนาดมุมภาพ, ข้อความบนจอ, เสียงบรรยาย, วินาที และหมายเหตุการผลิต
   - **Pre-production Interactive Checklist (สไลด์ 29):** เช็กลิสต์ตรวจแผนงาน 7 ข้อ ติ๊กถูกได้จริง พร้อมระบบคำนวณคะแนนและระดับความพร้อมแบบเรียลไทม์
   - **Interactive Knowledge Quiz 10 ข้อ (สไลด์ 32):** ข้อสอบวัดผลสัมฤทธิ์ 10 ข้อ ตรวจคำตอบทันที แสดงสีเขียว/แดง มีคำอธิบายเฉลยและเหตุผล สรุปคะแนนสะสม และปุ่มเริ่มทำใหม่
   - **Interactive Glossary (คลังคำศัพท์เทคนิค):** คลิกคำศัพท์ไฮไลต์เพื่อเปิดการ์ดความหมายด่วน หรือกดปุ่ม `G` เพื่อเปิดโมดัลค้นหาคำศัพท์ทั้งหมด

4. **Teacher Presentation Mode (โหมดผู้สอนมืออาชีพ):**
   - **Speaker Notes Drawer (กดปุ่ม `N`):** แถบเปิดบทบรรยายสำหรับครูผู้สอน (whatToSay, realLifeExample, guidingQuestion, expectedAnswer, timeRecommended)
   - **Presenter Console (กดปุ่ม `P`):** หน้าต่างควบคุมผู้สอน มีนาฬิกาจับเวลาสอน (Timer), แสดงสไลด์ปัจจุบัน, สไลด์ถัดไป, และบทบรรยายครู
   - **Dual Screen Sync:** รองรับการแยกหน้าต่าง 2 จอ (หน้าต่างหนึ่งฉายโปรเจกเตอร์ อีกหน้าต่างหนึ่งเป็นจอมอนิเตอร์ครู) ซิงก์การเปลี่ยนสไลด์อัตโนมัติผ่าน `BroadcastChannel`

5. **Save as PDF / Print Mode (16:9 ทุกสไลด์):**
   - คลิกปุ่ม **Save as PDF** หรือกดพิมพ์จากเบราว์เซอร์
   - ระบบตั้งค่า `@media print` จัดพิมพ์สไลด์ขนาด 16:9 พอดีหน้ากระดาษ ซ่อนแถบเครื่องมือ และแสดงสาระสำคัญของทุกสไลด์ครบถ้วน

## 2. แป้นพิมพ์ลัดสำหรับครูผู้สอน (Keyboard Shortcuts)

| ปุ่มลัด | การทำงาน |
|:---:|:---|
| <kbd>&rarr;</kbd> หรือ <kbd>Space</kbd> | ไปยังสไลด์ถัดไป (Next Slide) |
| <kbd>&larr;</kbd> | ย้อนกลับไปสไลด์ก่อนหน้า (Previous Slide) |
| <kbd>Home</kbd> | ข้ามไปยังสไลด์แรกสุด (First Slide) |
| <kbd>End</kbd> | ข้ามไปยังสไลด์สุดท้าย (Last Slide) |
| <kbd>G</kbd> | เปิด/ปิด คลังคำศัพท์เทคนิค (Glossary Modal) |
| <kbd>N</kbd> | เปิด/ปิด แถบบันทึกคำอธิบายสำหรับครู (Speaker Notes Drawer) |
| <kbd>P</kbd> | เปิด/ปิด โหมดผู้สอน (Presenter Console) |
| <kbd>F</kbd> | สลับโหมดเต็มหน้าจอ (Fullscreen Mode) |
| <kbd>Esc</kbd> | ปิดหน้าต่างโมดัล / ปิดแถบคำอธิบาย / ออกจากเต็มจอ |

## 4. แผนการจัดการเรียนรู้ 8 ชั่วโมง (Lesson Plan Summary)

### สัปดาห์ที่ 3 (ชั่วโมงที่ 1–4): ทฤษฎีวิเคราะห์โจทย์ & เขียนบรีฟ
- **ชั่วโมงที่ 1:** ความหมายและความสำคัญของการวางแผนผลิตสื่อดิจิทัล, ตัวอย่างเริ่มถ่ายทันที vs วางแผนก่อน (สไลด์ 1–6)
- **ชั่วโมงที่ 2:** การวิเคราะห์โจทย์ 3 ส่วน, 6 คำถามสำคัญ, กรณีศึกษาร้านเสื้อหม้อห้อม, การกำหนดวัตถุประสงค์ (สไลด์ 7–12)
- **ชั่วโมงที่ 3:** การวิเคราะห์ผู้รับสาร 6 ด้าน, พฤติกรรมนักท่องเที่ยว, การกำหนดสารสำคัญ และข้อมูลสนับสนุน (สไลด์ 13–16)
- **ชั่วโมงที่ 4:** 4 แนวคิดการนำเสนอ, มูดบอร์ดและลิขสิทธิ์, โครงสร้างบรีฟ 11 หัวข้อ และฝึกเขียนบรีฟ 1 หน้า (สไลด์ 17–20)
- **ชิ้นงานสัปดาห์ที่ 3:** เอกสารบรีฟ 1 หน้า พร้อมรายการข้อมูลที่ต้องตรวจสอบเพิ่มเติม

### สัปดาห์ที่ 4 (ชั่วโมงที่ 5–8): สตอรี่บอร์ด 6 ช่อง & ปรับปรุงงาน
- **ชั่วโมงที่ 5:** ความแตกต่างระหว่าง บรีฟ บท และสตอรี่บอร์ด, 7 องค์ประกอบในแต่ละช่อง (สไลด์ 21–22)
- **ชั่วโมงที่ 6:** สตอรี่บอร์ดมาตรฐาน 6 ช่อง 30 วินาที, การซ้อมจับเวลา, 6 หลักการออกแบบภาพ (สไลด์ 23–25)
- **ชั่วโมงที่ 7:** โครงสร้าง 3 ตอน (เปิด-ขยาย-ปิด), ทรัพยากร 4 บทบาท, แผนสำรองความเสี่ยง 4 ประการ (สไลด์ 26–28)
- **ชั่วโมงที่ 8:** Checklist ตรวจแผนงาน 7 ข้อ, บันทึกการปรับปรุงงาน 2 จุด, กิจกรรมกลุ่ม และแบบทดสอบ 10 ข้อ (สไลด์ 29–32)
- **ชิ้นงานสัปดาห์ที่ 4:** สตอรี่บอร์ด 6 ช่อง พร้อมตารางบันทึกการปรับปรุงงาน 2 จุด และนำเสนอผลงาน

## 5. การเปิดใช้งานและเผยแพร่บน GitHub Pages (Deployment)

1. **การเปิดใช้งานบนเครื่องในเครื่อง (Local Testing):**
   - รันผ่าน Web Server (เช่น XAMPP Apache) โดยเปิดเบราว์เซอร์ไปที่:
     `http://localhost/learning/21910-2008/`
   - หรือเปิดไฟล์ `index.html` โดยตรงบนเบราว์เซอร์ Google Chrome, Microsoft Edge, Safari หรือ Firefox

2. **การเผยแพร่บน GitHub Pages:**
   - นำโฟลเดอร์หรือไฟล์ทั้งหมดขึ้น Git Repository
   - เปิดไปที่ **Settings > Pages** ใน GitHub Repository
   - เลือก Branch และ Directory แล้วกด **Save**
   - ตัวโปรเจกต์มีสคริปต์ตรวจจับ Base Path และไฟล์ `.nojekyll` รองรับการทำงานใต้ Subpath Repository โดยอัตโนมัติ ภาพและฟังก์ชันจะแสดงผลครบถ้วน 100%
