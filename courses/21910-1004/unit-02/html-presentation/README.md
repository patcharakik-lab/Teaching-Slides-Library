เปิดเว็บเบราว์เซอร์ (Google Chrome หรือ Microsoft Edge) แล้วพิมพ์ URL:

ดับเบิลคลิกเปิดไฟล์ `index.html` ในโฟลเดอร์:

## 3. ปุ่มลัดแป้นพิมพ์สำหรับครูผู้สอน (Teacher Keyboard Shortcuts)
| แป้นพิมพ์ | ฟังก์ชันการทำงาน |
| :---: | :--- |
| `?` | เปิด/ปิด หน้าต่างคู่มือปุ่มลัดสำหรับครูผู้สอน (Shortcuts Modal) |
| `→` หรือ `Space` | ไปยังสไลด์ถัดไป |
| `←` | ย้อนกลับสไลด์ก่อนหน้า |
| `Home` | ข้ามไปยังสไลด์แรก (สไลด์ปก 1) |
| `End` | ข้ามไปยังสไลด์สุดท้าย (สไลด์สรุป 35) |
| `T` | เปิด/ปิด สารบัญสไลด์ทั้งหมด 35 สไลด์ (Table of Contents) |
| `G` | เปิด/ปิด คลังคำศัพท์วิชาชีพ (Glossary Modal) |
| `N` | เปิด/ปิด แถบบันทึกและบทบรรยายสำหรับผู้สอน (Speaker Notes) |
| `P` | เปิดหน้าต่างจอผู้สอนสำหรับฉายสองหน้าจอ (Presenter View) |
| `I` | เปิดกล่องเครื่องมือนำเข้าภาพผ่าน URL (Universal Image Import) |
| `F` | เปิด/ปิด โหมดแสดงผลเต็มหน้าจอ (Fullscreen) |
| `ESC` | ปิดหน้าต่างขยายภาพ (Lightbox) หรือหน้าต่างป็อปอัปทุกประเภท |

## 4. ฟีเจอร์เด่นระดับพรีเมียม (V12.1 Projector Ready)
1. **Projector-Ready Typography Standards (บน Canvas 1600 × 900 px):**
   - หัวข้อสไลด์: 48–60 px (อ่านออกชัดเจนจากแถวหลังสุดของห้องเรียน)
   - หัวข้อหลัก: 36–44 px
   - หัวข้อการ์ด: 32–38 px
   - เนื้อหาปกติ: 28–34 px
   - คำอธิบายการ์ด: 26–30 px
   - ป้ายกำกับ / Tag: 24–28 px
   - **กฎเหล็ก:** ไม่มีตัวอักษรใดเล็กกว่า 24 px บนพื้นที่สไลด์
2. **Smart Content Splitting (35 สไลด์โปร่งสบาย):**
   - แบ่งเนื้อหาที่มีความหนาแน่นสูงออกเป็น 2–3 สไลด์ย่อย เพื่อไม่ให้ตัวอักษรแออัด
   - จุดประสงค์การเรียนรู้ (สไลด์ 2 & 3)
   - ช่องทางการชำระเงิน (สไลด์ 22, 23 & 24)
   - 5 ภัยคุกคามสำคัญ (สไลด์ 26 & 27)
3. **Responsive 16:9 Scale Wrapper & URL Hash Routing:**
   - สไลด์รักษาสัดส่วน 16:9 เสมอ ไม่ล้นจอ และคงแถบควบคุมด้านล่างไว้ครบถ้วน
   - มี URL Hash เช่น `#1` ถึง `#35` จดจำสไลด์ปัจจุบันแม้กด Refresh หรือเปิดปิดหน้าจอ
4. **Universal Visual Zoom & Lightbox (PART 21.6):**
   - รูปภาพประกอบทุกภาพในสไลด์สามารถคลิกเพื่อขยายเต็มจอ รองรับการซูมเข้า/ออก (Zoom In/Out), เลื่อนภาพ (Drag-to-Pan), หมุนลูกกลิ้งเมาส์ และกด `ESC` เพื่อปิด โดยไม่รบกวนการเปลี่ยนสไลด์
5. **Universal Image URL Import & Asset Manager (PART 21.2):**
   - กล่องเครื่องมือสำหรับครูผู้สอนในการวาง HTTPS Image URL จากภายนอก ดูตัวอย่าง ใส่คำบรรยาย และบันทึกลงในสไลด์เป้าหมายได้ทันทีผ่าน LocalStorage
6. **Presenter Mode (Dual Screen Sync):**
   - รองรับการแยกจอผู้สอนและจอโปรเจกเตอร์ในห้องเรียน ซิงค์สถานะการเปลี่ยนสไลด์แบบเรียลไทม์ผ่าน `BroadcastChannel`
7. **Interactive Learning Components:**
   - เครื่องคำนวณตะกร้าสินค้าแบบสด (Live Cart Calculator 620 บาท)
   - เครื่องมือช่วยตัดสินใจเปรียบเทียบร้านค้า (Shop A vs Shop B 290 บาท)
   - แผนผังตรวจสอบ 9 สถานะคำสั่งซื้อในระบบจัดการคำสั่งซื้อ (OMS Status Explorer)
   - เครื่องจำลองการตรวจสอบสลิปโอนเงินและป้องกันสลิปปลอม (Slip Verification Checklist)
   - ระบบจำลองการติดตามหมายเลขพัสดุ (Tracking Number Simulator)
   - แผนผังจำลองการทำงานของ Payment Gateway
   - คลังข้อสอบทบทวนความรู้ 10 ข้อ (Knowledge Check Quiz Engine) พร้อมเฉลยและคำอธิบายละเอียด
8. **Print to PDF Support:**
   - รองรับคำสั่งพิมพ์สไลด์ขนาด 16:9 สไลด์ละ 1 หน้าอย่างสวยงาม ไม่มีข้อความตกขอบ และซ่อนแถบเครื่องมืออัตโนมัติ
