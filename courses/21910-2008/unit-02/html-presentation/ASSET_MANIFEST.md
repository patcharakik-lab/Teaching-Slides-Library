## 2. นโยบายการจัดการไฟล์และเส้นทางสัมพัทธ์ (Asset Path Policy)

1. **Relative Asset Paths:** ทุกเส้นทางของภาพอ้างอิงแบบ Relative เช่น `assets/images/mohom-indigo-craft.jpg` ไม่ใช้ Absolute Path ของระบบคอมพิวเตอร์ และไม่ใช้ Temporary URL
2. **GitHub Pages Ready:** รองรับการ Deploy ทั้งแบบ Root Domain และ Subpath Repository โดยมีสคริปต์ตรวจจับ `window.__ASSET_BASE_URI__` ใน `index.html` และฟังก์ชัน `assetUrl()` ใน `app.js`
3. **Nojekyll File:** มีไฟล์ `.nojekyll` ที่โฟลเดอร์หลัก เพื่อป้องกันไม่ให้ GitHub Pages เพิกเฉยต่อโฟลเดอร์หรือไฟล์ขึ้นต้นด้วยสัญลักษณ์พิเศษ
4. **Image Fallback Protection:** หากเกิดข้อผิดพลาดในการโหลดภาพ ระบบจะแสดง Fallback อย่างปลอดภัยภายในกรอบภาพ (Frame-bounded) โดยไม่หลุดออกจากสไลด์และไม่ทับแถบควบคุม
